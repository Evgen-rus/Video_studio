# assets/

- `screenshots/` — безопасные screenshots продукта.
- `recordings/` — raw screen recordings; видеофайлы игнорируются Git по умолчанию.
- `logos/` — брендовые ассеты.
- `music/` — разрешённые музыкальные файлы/референсы.
- `fonts/` — локально разрешённые шрифты; не коммить файлы, если лицензия этого не позволяет.
- `private/` — приватные/клиентские материалы; содержимое всегда игнорируется Git.

Не помещай сюда секреты, токены или реальные CRM-персональные данные.
