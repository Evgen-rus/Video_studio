# projects/

Один ролик = один каталог:

```text
projects/neuro-rop-promo/
projects/leadrecord-promo/
```

Внутри ролика должны лежать его Remotion source, локальный `package.json`, storyboard/spec и project-specific assets либо ссылки на общие безопасные assets.

Не модифицируй исходный продуктовый репозиторий ради ролика без явного разрешения.
