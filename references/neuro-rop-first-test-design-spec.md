# НейроРОП — первый production workflow test

Статус: creative direction и storyboard подтверждены; производство ожидает безопасные UI-материалы.

## Продуктовый бриф

| Параметр | Решение | Основание |
|---|---|---|
| Продукт | НейроРОП | Пользовательский выбор |
| Цель | За 8–9 секунд показать ценность контроля сделок через реальный интерфейс | Пользовательский бриф |
| Аудитория | РОП | Подтверждённый сценарий и UI-копирайт |
| Ключевая ценность | Найти сделку, требующую внимания, и увидеть проблемную зону/следующий шаг | Подтверждённый storyboard |
| Формат | 1920×1080, 16:9, 30 fps, 261 кадр (8,7 секунды) | Пользовательский бриф |
| Звук | Без BGM; только аккуратные SFX | Пользовательский бриф |
| Данные | Только фиктивные или явно санитизированные | Политика проекта |

## Визуальное направление

- Реальный интерфейс НейроРОП остаётся основной визуальной системой: его типографика, цвета, плотность, радиусы и поверхности.
- Движение: профессиональное и спокойное; один смысловой акцент за раз, без декоративной россыпи glint.
- Styleframe-сравнение пропущено: пользователь прямо выбрал реальный UI НейроРОП и конкретный creative path. Репрезентативные still-кадры обязательны после получения финальных screenshot-материалов.

## Функция → движение

| Функция | Shot card / адаптация | Результат |
|---|---|---|
| Найти проблемные сделки | `spotlight-hero-card` → прожектор и плавный push-in на вкладку «Требуют внимания» со счётчиком | Мгновенно задаёт объект внимания |
| Отфильтровать портфель | `type-and-filter` → без набора текста: клик по вкладке, последовательное исчезновение нерелевантных строк, фиксация целевой сделки | Причина и результат читаются как одно действие |

| Закрыть брендом | Спокойный wordmark outro без morph | Логотип и слоган удерживаются не менее 1 секунды |

## Подтверждённый экранный текст

- Вкладка: «Требуют внимания».
- Блоки: «Контроль качества ведения сделки», «Следующий шаг», «Фокус разбора», «Вывод для РОПа».
- Фиктивная сделка: «Пилот — Север»; этап «Переговоры».
- Вывод: «Следующий шаг после последнего контакта не зафиксирован.»
- Вопрос: «Что согласовано с клиентом и когда следующий контакт?»
- Финал: «НейроРОП» — «Фокус на следующем шаге.»

## Материалы и safety gate

До реализации нужны:

1. Два согласованных санитизированных состояния одного экрана: dashboard до фильтра и после выбора «Требуют внимания» с нужной сделкой/detail.
2. Предпочтительно 3840×2160 PNG (viewport 1920×1080, deviceScaleFactor 2) либо безопасный локальный demo-state для такого capture.
3. Официальный SVG-логотип; при его отсутствии разрешён текстовый wordmark «НейроРОП».

Запрещено использовать экран с реальными клиентами, контактами, суммами, Bitrix ID, токенами или внутренними данными. Нельзя запускать Bitrix sync, AI-анализ или mutating UI-действия ради capture.

## Производственная проверка

- Targeted TypeScript/Remotion check.
- Still QA минимум на кадрах 21, 87, 101, 158, 205 и 245.
- Полный render 1920×1080/30fps с SFX.
- Проверка резкости UI, bbox, пауз, SFX sync и отсутствия чувствительных данных.
- Независимый final review до статуса DONE.
